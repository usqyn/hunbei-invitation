# 虚拟人婚礼模板 - 浪漫红色系

这是虚拟人婚礼请柬模板 - 红色系版本

## 素材内容

### 照片区域素材
- `couple-photo-1.jpg` - 新人合影主图
- `couple-photo-2.jpg` - 新人合影副图
- `couple-photo-3.jpg` - 结婚登记照
- `couple-photo-4.jpg` - 婚纱照特写

### 装饰元素
- `decoration-hearts.png` - 爱心装饰
- `decoration-flower.png` - 花卉装饰
- `decoration-borders.png` - 边框装饰
- `decoration-sticker.png` - 贴纸装饰

### 文字排版
- `title-style.png` - 标题样式
- `date-style.png` - 日期样式
- `name-style.png` - 新人姓名样式

## 图片规格
- 照片尺寸建议：750x1000 或 1000x750
- 文件格式：JPG/WEBP（照片）、PNG（装饰元素）
- 文件大小：单张建议控制在 500KB 以内

## 使用场景
此模板适用于中式婚礼、传统婚礼、喜庆风格婚礼请柬
