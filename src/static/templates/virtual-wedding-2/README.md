# 虚拟人婚礼模板 - 清新白色系

这是虚拟人婚礼请柬模板 - 白色系版本

## 素材内容

### 照片区域素材
- `wedding-photo-1.jpg` - 婚纱照主图
- `wedding-photo-2.jpg` - 婚纱照副图
- `wedding-photo-3.jpg` - 户外婚礼照
- `wedding-photo-4.jpg` - 婚礼仪式照

### 装饰元素
- `decoration-heart-ring.png` - 爱心戒指装饰
- `decoration-flowers.png` - 花束装饰
- `decoration-border-white.png` - 白色边框装饰
- `decoration-love-sticker.png` - 爱情贴纸装饰

### 文字排版
- `title-romantic.png` - 浪漫标题样式
- `date-elegant.png` - 优雅日期样式
- `couple-name-style.png` - 新人姓名样式

## 图片规格
- 照片尺寸建议：750x1000 或 1000x750
- 文件格式：JPG/WEBP（照片）、PNG（装饰元素）
- 文件大小：单张建议控制在 500KB 以内

## 使用场景
此模板适用于西式婚礼、现代婚礼、清新风格婚礼请柬
